# 🧑‍💻 Sorting-Visualizer

**Sorting-Visualizer** is a React.js application that visualizes the process of various sorting algorithms, including **Bubble Sort**, **Quick Sort**, **Merge Sort**, and **Insertion Sort**. Users can interact with the app by controlling the array size and observing how these algorithms sort the data in real-time, with smooth animations.

## 🌟 Features

- **Visualizes multiple sorting algorithms**:
  - Bubble Sort
  - Quick Sort
  - Merge Sort
  - Insertion Sort
    
- **Interactive controls**:
  - Adjust the array size dynamically.
  - Select the algorithm you want to visualize.
    
- **Smooth animations**
  - for a better understanding of sorting processes.
