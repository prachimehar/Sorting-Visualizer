# Sorting-Visualizer
A React.js app that visualizes sorting algorithms (Bubble Sort, Quick Sort, Merge Sort, Insertion Sort) with smooth animations. Users can control array size and see algorithms sort in real-time.

# Features
Visualizes multiple sorting algorithms.
Control array size and choose sorting algorithms.
Smooth animations for better understanding.

# Getting Started:
Prerequisites - Node.js installed.

# Installation
Clone the repo: git clone https://github.com/prachimehar/Sorting-Visualizer
cd sorting-visualizer

Install dependencies: npm install

Run the app : npm start
